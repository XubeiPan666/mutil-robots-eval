# Documentation

Future Robots Evaluation is the simulation evaluation companion to [Future Robots](https://github.com/zhangzaibin/future-robots), from [Evolving Machines Lab](https://zhangzaibin.github.io/evolving-machines/).

| Guide | What you will find |
| --- | --- |
| [Installation](installation.md) | Simulator environment, GPU rendering, assets, and a local smoke test |
| [Evaluation](evaluation.md) | Single-server and per-arm runs, task conditions, seeds, metrics, and perturbation replay |
| [Architecture](architecture.md) | Repository map, model-server contract, and adding a policy or task |

Start with installation, confirm a single episode, then run the task suite. Model training and serving instructions live in Future Robots; this repository provides the environment side of that connection.
